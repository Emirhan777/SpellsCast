SpellsCast includes a full offline iPhone game, standalone rune practice, and a controller for the companion browser game. No login, purchase, subscription, or account is required.

To review the new second-player invitations:
1. Open https://emirhan777.github.io/SpellsCast/ on a separate computer and keep that screen open.
2. Connect the iPhone using Join an existing game and the QR or six-digit room code. No account is required.
3. Before starting a round, tap Invite second player on the connected screen or online wand controls. The native share sheet contains a link to this same room. The computer switches to Wizard duel.
4. Send the invite to a second phone, or copy it. The recipient can use the browser controller or choose Open in SpellsCast to use the installed app. The first phone remains connected while sharing; a real network disconnection still requires reconnecting.
5. Both players connected replaces the invite button when the room is full. Select Start duel. Invitations are hidden during an active round; no third player can join.
6. If a system share sheet is unavailable, a dialog provides Copy invite link and a selectable URL. The offline on-device game remains solo.

To review the on-device game without another screen:
1. Choose Play on this device. The game opens in landscape.
2. Tilt is selected by default. Hold anywhere on the game screen, allow motion if prompted, tilt through a displayed rune, then release. The first recognized spell starts a round. A tap or permission approval alone does not start play.
3. To test without sensors, choose Finger mode in the top menu. Draw the red V-shaped Expel rune directly on the screen and lift your finger. This starts the game. Keep casting runes matching the targets.
4. Each mode keeps its own local best score. Switching modes confirms ending the current run. Cast another spell after game over to restart.
5. Mirror explains AirPlay and HDMI setup; actual mirroring starts in iOS Control Center. Local play pauses while backgrounded or opening the guide. In this mode, mirroring shows the full landscape game.

To review connected play:
1. On a separate computer, open https://emirhan777.github.io/SpellsCast/ and leave it open. Click the page once to enable audio.
2. On the iPhone, choose Join an existing game, then Scan the game QR. Allow camera access and scan the code shown by the computer. Alternatively, enter the six-digit room code shown on the computer.
3. Choose Use motion wand and allow motion access, or choose Use touch controls.
4. Tap Start game. Hold the cast pad, move the phone through a rune, and release. In touch mode, draw the rune on the pad and lift your finger.
5. The score and lives appear on the phone. Two phones can join one room.

To review starting from the app:
Choose Start a game, then Create a game link. Send or copy the link to your computer. Open it on the computer and select Open game on this screen. Return to the iPhone app; it pairs automatically. Choose a control mode and tap Start game. An unused link expires after ten minutes.

To review without another device, camera, or motion access:
Choose Practice your spells. Draw each displayed rune with your finger. Tap another spell to change the guide. This mode works offline.

The camera is used only to scan the room QR and does not save or upload images. Motion controls convert orientation to wand coordinates. Sound plays on the computer or TV game screen. A TV must have a compatible browser, or display a computer via HDMI or Mac AirPlay. Standard iPhone mirroring displays the phone controller.

To review Wizard duel:
On the computer game screen, select Wizard duel and a match length. Connect two phones to the same room, then select Start duel. Both phones display individual scores, opponent scores, the timer, and the final result. The first correct cast received by the game claims each target for one point. Select Rematch to play again. Classic mode and offline practice can be reviewed using one phone.
